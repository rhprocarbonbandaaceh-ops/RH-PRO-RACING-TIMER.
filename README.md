# RH PRO RACING TIMER v3 — Neon Racing UI

Android GPS drag performance timer with a refreshed RH PRO Racing Team purple/black racing interface.

## Features
- GPS-based elapsed timer and distance tracking
- 201 m and 402 m split timing
- Speed display in km/h
- Local race history and best-time tracking
- RH PRO Racing Team logo and neon carbon-inspired UI

## Build
Open this folder in Android Studio, allow Gradle sync to finish, then select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

The app requests location permission because timing and distance are measured using the phone's GPS. For meaningful results, use outdoors with a clear GPS signal. This is a phone-GPS timer, not a certified motorsport timing device.
